# Vibe Coding · 直播表情特效

当前版本 **v68**。浏览器本地识别笑容：微笑下雨、大笑放烟花，粒子与头部、人物轮廓和手部发生碰撞。

- **01 写实**：双层放射、错落复绽、末段火焰式摆动与细闪消散。
- **02 礼物**：糖果与柔彩糖果随机，物件碰撞变为彩纸，雨滴碰撞变为短暂圆形碎滴。
- **03 扁平**：四种花型自动轮换，五个运动载星分别绽放。
- 左侧锁定播放雨滴／烟花；再次点击解除，恢复表情控制。

## 在线体验

[在线演示](https://oliverwu-lab.github.io/live-expression-effects/) · [公开源码](https://github.com/OLIVERWU-LAB/live-expression-effects)

请允许浏览器访问摄像头；也可先使用模拟预览。画面不上传，不请求麦克风。首次启动需要下载同源模型，之后优先复用本机缓存。

## 本地运行与部署

需要 Node.js 20+，无需安装应用依赖。

```sh
npm start
npm test
npm run build
```

本地预览：`http://127.0.0.1:4173/`。构建产物在 `.pages/`，可直接用作静态站点根目录。相对资源路径支持 GitHub Pages 的项目子目录。当前使用 GitHub Pages 的 `gh-pages` 分支发布；先在本地运行测试与构建，再将 `.pages/` 内容推送至该分支。可选的 Actions 配置样例保存在 `docs/pages-workflow.yml.example`。

完整源码保留旧材质的回归样本，正式构建仅收录当前运行所需资源。未发布录屏、人物截图或本机版本历史。第三方运行库与模型的说明保留在 `dist/vendor/`。

## 性能与复盘

- 推理在 Worker 执行，一次只有一个在途帧；脸部、轮廓、手部分频处理。
- 粒子、尾迹、缓存与画布像素均有预算；低性能时保留视觉结构并降低粒子数。
- 礼物使用离线渲染图集；写实复用发光纹理，不逐粒子实时模糊。
- [性能与 ROI：实现、实测和验证范围](docs/性能与ROI.md)
- [Vibe Coding 复盘：167 字，含实际纠偏 Prompt](docs/Vibe-Coding复盘.md)

本机测试不能替代中档手机摄像头全链路、内存与温升实测。

## 移动端修复

竖屏雨量增加、写实雨线加粗；礼物素材与识别恢复有中央提示，识别异常自动重试。扁平完整保留五朵花和内层结构，并适配竖屏画幅；关闭扁平人物反光，增强写实受光。手机图集解码 RGBA 尺寸估算减少约 44%，实际峰值内存及真机长时间摄像头体验仍需验证。详见 [v65 改动](docs/v65-移动端体验修复.md)。

当前默认进入 01 写实；底部强度条与第一题、第三题统一为蓝色 #1034ce、橙色 #ff4d00。详见 [v66 调整](docs/v66-默认写实与蓝橙配色.md)。
