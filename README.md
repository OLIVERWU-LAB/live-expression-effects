# Vibe Coding · 直播特效

当前版本 **v73**。浏览器本地识别笑容，以微笑触发雨滴、大笑触发烟花；粒子与头部、人物轮廓和手部碰撞。

## 运行与体验

需要 Node.js 20+，应用无需安装运行依赖。

```sh
npm start
npm test
npm run build
```

本地打开 http://127.0.0.1:4173/ 。在线摄像头体验需 HTTPS。

- **01 写实**：仅使用原版优化烟花，保留内外圈、彩色拖尾、错落复绽与圆点细闪。
- **02 礼物**：错落散射，糖果／柔彩糖果逐发随机。物件碰撞后变为彩纸；雨滴碰撞后变成短暂的圆形碎滴。
- **03 扁平**：花瓣、同心礼花、星冠绽放、锦簇花火自动轮换。首次小花爆开、五个载星分散，再从载星实时位置绽放。
- 左侧「锁定播放」只有雨滴、烟花。再次点击已选项解除锁定，恢复表情控制。换风格时保留锁定类型。
- 初始页仅有摄像头与模拟预览入口；音效默认遵循用户本机设置。真实录音音色由程序控制升空、主炸、复绽及细闪强弱，完整渐弱收尾；中性表情显示“笑一笑吧”。所有风格均不生成镜头上的拖尾水痕。
- 摄像头模式使用真实推理；预览模式使用模拟信号与人物。识别画面留在本机，不上传。

## 性能与工程

人脸与人物／手部任务分别在 Worker 执行，沿用 v69 的原模型、输入尺寸及笑容判定。轻量替代模型因用户实测识别退化已撤回，没有发布。写实保留全身置信度遮罩受光，礼物／扁平保留碰撞并关闭反光。

礼物图集减为两张 WebP、共约 0.42 MB；正式部署只携带无损压缩模型和运行库，完整部署约 16.2 MB，初始人脸传输仍约 6.32 MB。身体／手部模型按原流程准备，不能用减少识别功能换取更小数字。手机低预算按每朵花的圆周和层级采样；扁平／礼物直接叠加原生视频。雨量、水面曲线和落水碎滴也已调整。用户已确认恢复后的表情和轮廓正常；水面细高光与低幅折射在 v71 补回。

v59 去除重复遮罩绘制与拖尾分段的重复调色，待机页面不执行特效绘制。详见 [性能与 ROI](docs/性能与ROI.md)；帧准备基准不代表所有手机的实际 FPS。

运行 `node tools/live-files.mjs` 可输出正式部署文件清单，包含实时入口、业务依赖、识别模型及两套实际使用的礼物材质；不包含历史 QA 页与旧材质。完整源码仍保留历史对比和回归测试，用于追溯。部署包根目录直接作为静态站点根目录。

## GitHub Pages

当前使用 GitHub Pages 官方分支发布：先运行测试与构建，再将 `.pages/` 推送到 `gh-pages` 分支；Pages 来源选择该分支根目录。可选自定义工作流样例放在 `tools/pages-workflow.yml.example`，本次未增加 OAuth 权限。`npm run build` 无安装依赖，部署文件全部使用相对路径，兼容项目子目录；首次摄像头访问需要用户允许。
