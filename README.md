# Vibe Coding · 直播特效

浏览器中的 AR 表情互动原型：微笑下雨，大笑绽放烟花，粒子与头部、人物轮廓及手部碰撞。

- [在线体验](https://oliverwu-lab.github.io/live-expression-effects/)
- [公开源码](https://github.com/OLIVERWU-LAB/live-expression-effects)
- [Vibe Coding 复盘（200 字以内，含纠偏 Prompt）](docs/Vibe-Coding复盘.md)

## 体验

允许摄像头权限后，保持微笑触发雨滴，加深笑容触发烟花；右上角可以开启声音、全屏或隐藏界面。可在写实、礼物、扁平三种风格间切换。左侧「锁定播放」用于单独检查雨滴或烟花，再次点击解除锁定，恢复表情控制。

未开启摄像头时，可通过「预览效果」检查动画；这是模拟输入，不代替真实摄像头识别。在线摄像头需要 HTTPS，本地 localhost 可直接体验。首次需要准备同源识别资源，进度会在画面中显示；后续优先复用缓存。视频帧在本机处理，不上传。

## 本地运行

需要 Node.js 20 或以上。无需安装运行依赖。

```sh
npm start
```

打开 `http://127.0.0.1:4173/`。

```sh
npm test
npm run verify:assets
npm run build
```

构建产物位于 `.pages/`，可作为静态站点部署；当前演示使用 GitHub Pages。页面地址不需要任何版本参数，构建会为内部模块生成内容标识，避免缓存混用。

## 实现与性能

- 识别：人脸和辅助轮廓／手部分别在 Worker 中运行；每通道只允许一帧在途，按耗时分频，隐藏页面时暂停。保留验收后的模型与笑容判定。
- 视觉：写实和扁平使用程序粒子、记录的真实轨迹与有界绘制；礼物使用两张预烘焙 WebP 图集，避免浏览器逐物件计算三维网格与材质。
- 碰撞：分割遮罩、头部包围及手部几何共同参与；烟花左右交替升空，保持同一画幅下扁平烟花尺寸一致，并按可用空间移动整组展开，射线维持向四周运动；首次扫过人物轮廓即响应。屏幕环形装饰不与人物碰撞。
- 降级：按设备像素及粒子预算启动，再按绘制开销调整；按每朵花和层级采样，保留五个展开中心、内外层和末尾细闪，不强行删除活动组件。
- 音频：五段本地录音预先解码并复用，程序按真实视觉事件调整音量、音高、声像和渐弱；连续轻雨底声复用小缓冲，人物接触短暂让出背景空间。
- 交付：只保留实际依赖、两张图集、五段音频及校验过的压缩识别资源。历史版本、试验音色、旧材质、样式挑选页、调试面板和未压缩模型副本不进入当前工程与线上包。

完整资源约 16.1 MB，其中识别资源约 15.29 MB；首次人脸路径的模型与引擎约 6.32 MB，其他资源另计。两张礼物图集约 419 KB，五段音频约 119 KB。识别资产已使用 gzip 最高等级无损压缩，解压后逐项核对长度与 SHA-256；不通过缩减识别能力换取包体数字。

更多实现与验证范围见 [架构与性能](docs/架构与性能.md)、[交付说明](docs/交付说明.md)。素材来源见 [音效与许可](docs/音效与许可.md)。
