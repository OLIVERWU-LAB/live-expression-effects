# v72 · 实形图标、微笑提示与自然音效

用户确认 v70 表情与轮廓正常；随后否定 v71 的纯合成升空／爆炸音色，以及带额外装饰的图标。v71 已独立保存为未采用的试听记录，没有上线。本轮保留原识别和粒子运动，不再调整模型、判定或模拟。

## 最终体验

- 雨滴是一枚实心水滴，烟花是一枚四角星，笑脸为白色实形；无额外射线、第二颗雨滴、描边或半透明装饰。选中按钮保留深色图标，保证浅底对比。
- 检测到真实人脸、识别准备完成且持续约 700ms 没有微笑时，画面中间仅显示“笑一笑吧”。微笑、无人脸、暂停、预览或锁定播放时隐藏；停止摄像头时立即清除。无脸时沿用“让脸部进入画面”，不混用提示。
- 水面沿用本轮统一的平滑细高光和低幅折射；不恢复七条短波纹，不改变碰撞水位。写实保留全身受光，礼物／扁平只碰撞不反光。

## 声音修正

纯噪声／振荡合成未能达到参考录音的质感，因此撤回。当前采用用户原录音和已授权纸张录音作音色基础，由程序控制时序、强弱、位置及包络；不宣称这些声波是纯程序生成。

- 原始 shoot 保留自然音色，音调只作约 ±2% 的变化，按实际升空时长配合约 230ms 渐弱，不使用卡通式滑音。
- explode 保留完整自然衰减，不再用强低通噪声替代。大炸保留轻微的短回响；小炸较轻、音调变化收敛，无额外回响。扁平几朵花分别变化音量、音调和声像。
- shining / sparks 不再截取反复播放的 0.28s／0.85s 小切片。同类最多一条连续录音，同时随屏幕内实际细闪的亮度、密度、生命期与横向位置调节音量、滤波和声像。亮点消失后以约 380ms 逐渐收掉，不硬切；没有循环背景音。
- 礼物不播放闪光铺底，仅主炸和碰撞后的真实短纸张声。切换用短渐弱取消正在播放及未来回响，结束音源释放；以音频时钟补充有界清理。
