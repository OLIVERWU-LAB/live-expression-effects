# v79 · 均匀接续与碰撞声音

## 本轮调整

- 礼物烟花碰撞后产生彩带的薄纸声继续复用现有录音，播放速率从 0.97–1.03 提高至 1.16–1.38，增益从 0.0467–0.055 降至 0.025–0.042。每次独立选取音高和音量，保持至少160ms限频，没有增加定时器或新音源类型。
- 扁平发射不再被活动粒子数量的72%门槛阻塞。这个门槛会在两次较近发射后让系统等待上一组衰减，造成成对放、再停顿。改为每1.4–1.5秒逐枚接续，仍检查飞行中的火箭和排队载星；出生采样和总粒子预算由原世界模拟管理，不清空活组件，不补发过期发射。
- 人物雨滴碰撞增益改为0.20–0.224，再乘0.9–1.0的轻微变化；保留原80–105ms的三段碎雨实录，不恢复空腔“嘟”声。连续雨底声和水面接触增益不变。
- 修复仅剩碰撞水花、没有可见下落雨滴时直接停止声音的分支：新鲜人物／手部水花仍可触发，且不会为孤立水花启动连续雨底声。
- 停止或切换时，短声音源的结束时间不能被延长，以免播放越过当前片段进入下一个碎雨片段。短声包络稍多保留开头，仍快速衰减。
- 加载录音时防止无效PCM采样污染整个峰值和归一化增益：少数异常采样清零，异常比例过高则报解码错误，不将无效增益视为已准备好。此项是解码防护，不宣称已经在用户手机上证实了某种解码器故障。

雨滴配色、烟花大小／形状／运动、人物及手部模型与表情判定均保持v78，没有新增音频资源。

## 验证

319项自动化检查通过，新增覆盖混合花形逐枚接续、仅水花接触仍发声、停止不延长短声、礼物音高／音量独立变化，以及无效解码尾采样不会使增益变成NaN。

用实际世界模拟及1.4–1.5秒发射逻辑，对150/420预算、15/60 FPS进行46秒连续测试。v78单枚间隔约0.98–2.4秒，波动系数约23%–28%；v79约1.42–1.53秒（含帧量化），波动系数约2%。所有发射均完成五朵花，没有排队载星残留，最终清空；粒子不超过预算。

全绘制流程的15/24 FPS样本包括人物遮挡、碰撞前景、连续发射，仍未检出长白条候选。它是原生CPU Canvas检查，不等同于真实iOS GPU。

此前只检查整体混音不足以确认短接触声输出。本轮新增独立接触声检查：在相同输入下，v78仅水花情形触发0次、输出为0；v79触发7次，峰值约0.031，尾段归零。常规人物接触在隔离测试中的峰值约为v78的2.9倍。三种风格的实际录音与声音类离线混音均无削波，结束释放音源。离线AAC解码WAV统一安全重采样到44.1kHz，避免测试解码器的尾部无效采样影响新旧对比。工具没有实际听辨手机混音，不能替代实机试听或硬件延迟测量。
