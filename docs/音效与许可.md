# 音效与许可

运行时只加载五段同源录音，不访问第三方音频服务器。音色采用实录，程序控制触发、滤波、音高、声像、音量和完整渐弱；雨的连续底声为一次生成并复用的滤波噪声。

| 用途 | 来源 | 许可／说明 |
| --- | --- | --- |
| 主爆炸与小爆炸 | 用户提供的 explode.mp3 | 按用户指定用于本演示 |
| 碎光氛围 | 用户提供的 sparks.mp3 | 按用户指定用于本演示 |
| 升空 | [Whistle and Explosion Single_Firework · Rudmer_Rotteveel](https://freesound.org/people/Rudmer_Rotteveel/sounds/336008/) | CC0 1.0，截取0.18–0.96秒的升空片段 |
| 人物／水面碰撞 | [Rain on leaves · SamsterBirdies](https://freesound.org/people/SamsterBirdies/sounds/584272/) | CC0 1.0，截取约3.132、8.417、14.117秒的三处短接触，滤波并淡入淡出 |
| 礼物碰撞后纸屑 | [paper, thin, tracing, blueprint, rustle.wav · golovlev.sound](https://freesound.org/people/golovlev.sound/sounds/632220/) | CC0 1.0，截取0.35–0.73秒 |

CC0许可：https://creativecommons.org/publicdomain/zero/1.0/

三段短实录统一为单声道AAC。完整长原录音、旧切片、Fireworks2、Shining及未采用的纯合成音色不在当前包内。

识别运行库、模型及第三方许可记录保留在 `dist/vendor/LICENSE-APACHE-2.0.txt` 和 `dist/vendor/THIRD_PARTY_NOTICES.txt`。礼物图集为该原型离线烘焙资产。
