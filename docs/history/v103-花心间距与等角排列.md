# 花心间距、等角排列与白色细闪

上一轮只检查对向粒子速度相反，遗漏了相邻夹角是否相等：例如从八个方向抽出三组对向粒子，虽然中心对称，六个方向的间隔仍不等。星冠旁边的三颗伴星又在视觉上打乱了外圈间距。

现在精简粒子只保留完整的等角度子集，例如八颗星保留八颗或四颗，不再抽成六颗。正常预算下保留完整八向星冠；移除旁边拥挤的伴星与额外小星环。各层初始射线速度等大、等角，后续重力、阻力和碰撞继续作用。

每次主烟花分出三朵；宽裕的桌面场景可以有四朵。各朵花保持一致尺度，花心按宽松的浅弧展开，不再围绕一个中心挤出五朵。位置规划移除了已不再继承的载体残余速度占位，限制花心间距压缩，并为完整射线增加横向边界空间。升空间隔和0.8秒的初始花瓣保持。

白色细闪寿命延长，三种花型均允许外围短碎闪。自动检查实际绘制粒子后，白色细闪在彩色头部结束后保留约0.4至0.8秒，随后清空；没有恢复长条形拖尾频闪。

306项检查通过，新增相邻夹角等分检查（不再只检验成对）、真实出生花心间距、正常/最低预算星冠数，以及白色结尾时长。72组连续场景共1944朵花，圆环、必需层和细闪无缺失，队列无积压，全程未提高设备粒子上限。原有五朵花、伴星和短碎闪的旧断言按照用户此次要求更新，其余碰撞、尺度、帧率与存活检查保留。

答卷预览复用相同物理和绘制代码。已核对原生Canvas逐帧输出，浏览器操作仍被Work设置关闭，本轮未进行手机实机和摄像头测试。
