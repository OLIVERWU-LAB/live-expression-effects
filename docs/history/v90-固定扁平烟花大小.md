# 固定扁平烟花大小

修复上轮将发射侧与炸开位置绑定后，头偏向一侧导致该侧扁平烟花被缩小的问题。扁平的视觉尺寸只由画幅决定，不受头部左右位置和当前发射侧影响；左右升空、发射间隔、三种花型的轮换和自然径向射线保持。

优先在原尺寸下移动整组花束至可用空间。当窄画幅或靠近镜头的人物占据太多空间时，只调整五个载星的分散距离，保持每朵花的半径、组件尺寸和径向速度。规划阶段预测的五个出生点与运行时共用同一组距离参数；仍保留出生点安全检查，不移除任何花朵。

1280×720、头部横向位置30%/50%/70%的六组对照中，旧版整体比例约0.405至1.045，新版六组均为0.847。窄屏与较高头部位置也验证尺寸不变；三个花型在420粒子预算下均完整生成五朵花。
