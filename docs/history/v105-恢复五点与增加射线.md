# 恢复五点编排，增加均匀射出的组件

点位恢复到改成三朵之前最后一版的五朵编排（本地提交dfe0796）。直接恢复该版的载体初始速度、分支尺度、角度、错落起爆时间和位置规划。16组载体数据、24组手机/电脑头部位置与发射规划逐项比对旧版，通过后才使用；没有重新随机生成一套近似点位。

保持目前单朵均匀放射的形式，三种现用花型的主射线及星冠组件数增加约三分之一，四舍五入。例如24→32、16→21、8→11。正常手机与桌面预算下，另外核对实际入场数量，而不只检查原始生成量：12→16、8→11、4→5等均已生效。

采样改为把入场组件重新按360°/数量布置，支持七、十一等奇数。各层速度、基础尺寸、拖尾绘制和消散方式保留；组合尺度恢复旧版五点各自的配置。组件变多后，受限档位优先减少新生装饰散点，较低档位适当减少外围细闪的出生次数，保留其消散时长。没有增加设备粒子上限，也没有修改识别模型。

310项检查通过；72组连续场景共3240朵花，圆环、必需射线层、白色细闪无丢失，无出生队列积压。答卷预览与体验页使用相同代码。

已检查原生Canvas绘制；Work设置关闭了浏览器操作，本轮未进行手机实机或摄像头复测。
