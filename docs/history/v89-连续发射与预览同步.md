# 连续发射与预览同步

预览与摄像头体验共用 firework-playback.mjs：发射原点在左右两侧交替，只有成功发射才切换侧别。写实间隔1.5–1.66秒、礼物1.75–1.95秒、扁平1.4–1.5秒；锁定播放沿用同一节奏。延续真实物理时间和粒子工厂，不在单次烟花结束后重置画面。系统减少动态效果偏好仍保留原来的体验降速。

扁平在PC头部偏向一侧时，原来的“尽可能放大花型”搜索会反复落在另一侧。当前规划在请求侧寻找完整花束，必要时整体缩放，不改变射线角度或删除花朵。手机窄屏仍可在头顶的安全区域展开，由两侧交替升空。

写实主粒子不再等待原来的碰撞延时或只在下落时检测，首次扫过轮廓就响应。礼物沿用已确认的即时彩带碰撞。表情模型、雨滴、音效、素材图集与人物SVG构图均保持。

答卷从八张调整为六张预览，每种风格保留雨滴与烟花。扁平烟花在一张卡片中连续轮换同心礼花、星冠绽放、锦簇花火，注释为“烟花（三种形式）”。预览复用实际模块，取消开场跳过一秒及单发重置；保留独立暂停、进度定位、离屏暂停与静音。

验证：295项行为检查通过；原生CPU Canvas连续模拟18秒，三种风格分别发射12、10、13次并左右交替，扁平三种花型均出现；六张卡片定位回放一致，10个共享模块源码对齐，全部预览模块语法与依赖有效。未在用户手机上重新运行摄像头或测量浏览器GPU帧率。
