# 扁平烟花：轨迹与组件保留

跨屏斜射的原因是发射点固定在一侧，避让后爆炸位置却可能落在另一侧。现在优先在对应半屏选择完整尺寸的安全花型，发射点与爆炸位置一并规划，横向位移上限为画宽的16%且不超过上升距离的25%。占用一侧时选择可用空间并同步移动发射点。扩大横向展开预留，减少花朵贴边裁切。

缺组件的原因在新粒子入场阶段：每次出生可占共享池70%，前几朵花耗尽容量；后续没有显式保留只有一个实例的圆环，未入场的非发射器粒子会被丢弃。原检查只确认五个中心发射，没有覆盖每个花型层级。

现在对每朵花限制出生配额，为后续花和下一发预留空间；圆环、每个射线层和白色细闪先获得槽位，装饰点再分配余量。容量紧张时结构组件保留在有界队列，已显示组件继续自然消散。连续测试未发生排队延迟。

核验：301项测试；72组连续场景、3240朵花，圆环、必需射线层和细闪无遗漏，粒子数量没有超过150/300/420/650预算。360组位置规划保留花朵尺寸，最大上升偏角由约52.4度降至约14.0度。答卷预览复用相同修复。

本轮浏览器操作被Work设置关闭。已用真实模拟和原生Canvas绘制逐帧核对；未进行手机实机或摄像头测试。
