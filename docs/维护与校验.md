# 维护与校验

## 本轮范围

整理源码仓库的阅读入口、测试命名和历史文档位置，展开构建及资源检查工具的排版，删除未使用的构建工具导入，并提供统一的 `npm run check` 命令。

不修改 `dist/` 中的任何运行源码、HTML、CSS、音频、图集、模型与识别配置。答卷网站和线上体验的部署内容保持。

## 性能复核

- 实际运行目录与依赖清单一致：66个文件，没有额外的历史预览或未使用素材。
- 八项识别资源已无损压缩至15,291,599 B；重新用gzip等级9压缩，体积没有进一步下降。解压长度和SHA-256校验通过。
- 人脸与辅助推理分通道运行，各最多一帧在途；后台暂停及前台恢复仍由现有会话机制管理。
- 画布分辨率、粒子与拖尾采样、音源数量均有上限；图集、解码音频及纹理复用。
- 三种扁平花型的低预算、必需组件和运动检查保留。上一轮72组连续模拟覆盖3240朵花，无必需组件丢失或排队延迟；本轮只整理非运行文件，未改变这些行为。

## 可复现检查

`npm run check` 包含312项回归检查、资源校验和构建。另对本轮整理前后的每个运行文件及部署文件进行SHA-256比较，确认66个运行文件与67个部署文件完全一致。

没有为数字上的提速降低模型精度、改动识别阈值或删减当前视觉组件。本轮没有新增运行依赖，也没有新增线上下载资源。

未重新进行手机实机、摄像头、GPU、温升与全链路延迟测量，因此不声称达到某个通用帧率或加载时间，也不将自动检查通过当作所有浏览器行为保证。
