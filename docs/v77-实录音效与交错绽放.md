# v77 · 实录音效与交错绽放

## 实录声音

升空、水滴接触和礼物纸屑改用三段 CC0 真实录音，分别来自 Rudmer_Rotteveel 的礼花火箭、bxyorna 的水滴和 golovlev.sound 的薄描图纸。来源、作者、许可和原公开下载链接见「音效素材来源.md」。截取后单声道、高通去除低频厚重感、淡入淡出、64kbps AAC 编码，新增合计 25,011 B；不加载完整原录音。

升空片段为原作 0.18–0.96s，避开 1.15s 后的爆炸，保留约 4–6kHz 实际礼花哨声；增益 0.14，跟随真实飞行时长渐弱。主炸和小炸仍用用户的 Explode，细闪仍只用低音量 Sparks，不恢复 Fireworks2 或 Shining。

水滴碰撞改为真实水滴入水片段，按真实人物／水面接触触发，轻微变调与声像变化；人物接触至少间隔 170ms，播放约 240–265ms 以保留自然衰减。雨底声保持低音量程序噪声；不对每个可见雨滴创建音源。纸屑使用真实薄纸短响，高通 1700Hz，增益 0.14–0.165，只在礼物碰撞后散成纸屑时触发，最短间隔 160ms。

五段运行录音统一在资产准备阶段下载、解码，播放复用缓冲，没有播放时下载／解码／合成升空或纸屑 PCM。原音色保留在源码历史；旧程序短声只供历史测试兼容，正式体验传入已解码的水滴录音。

## 扁平烟花

- 接续不再等待上一组所有主要粒子进入尾段。最低发射间隔为 950–1110ms，保留飞行和预算门控；上一组仍完整存在时可以升空和绽放下一组。超过 72% 粒子预算或未来载星还在排队时，暂缓接续，不删除不透明组件。
- 三种复合花形的单朵倍率从整组的 0.62 提至 0.78，花瓣形式的展开半径增加 12%、花瓣尺寸增加 10%。中央细白闪仍保持原尺寸上限。
- 竖屏根据人物上方实际可用空间安排整组炸点和大小，并保留轻微左右交错。没有把分裂载星拉向固定坐标，也没有重定向为单侧喷射。空间很少时保留更保守倍率，不强行放到人物额头。
- 初次分裂的短命载星在开花前不再因头部碰撞偏转；真正绽放出来的粒子仍会与头部、身体和手碰撞。复合花形粒子碰撞延后至出生后 380ms，先呈现完整的径向打开过程。
- 保留原识别模型、表情判定、分割、手部几何、雨滴尺寸／密度和 v76 手机尾段彩色绘制保护。

## 验证和边界

313 项自动化检查通过：包括三段新资源格式和大小、五段资产准备、实际音源复用、真实水滴缓冲接入、音源结束释放；150/420 预算及 15/30 FPS 的连续烟花，所有发射最终都产生五朵花，队列与粒子会清空，不删除活载星。

在固定 12 个随机种子、三个人物高度、四种花形的模拟中，绽放后 0.5s 内的过早头部接触由 2853 次降至约 500 次，整体碰撞仍存在。复合花形首朵 300ms 时的直径，在测试的竖屏位置比 v76 大约 16%–37%。它们是固定输入对比，不代表所有人的真实姿态。

60 FPS 接续模拟，四种花形平均发射间隔约 1.04/1.34/1.27/1.27s（v76 为 1.43/2.09/1.82/1.74s）。15/24 FPS 原生 CPU Canvas 全流程检查包含遮挡、碰撞前景及交错烟花，粒子不超过 420，未检出长白条候选。手机 GPU 和真人试听仍需实机复核。

对实际 AAC 解码后的录音与真实声音类做三种风格的离线混音：波形有限、无削波、尾段归零和音源释放。工具不能直接听辨最终主观混音，也没有测量手机音频硬件延迟。

v76 独立源码 ZIP 和部署包保留；v77 另存完整源码、部署包与校验。用户录屏未加入公开源码或部署。
