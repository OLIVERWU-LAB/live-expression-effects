# v69 · 音效编排与矢量控件

## 界面

- 蓝色从上到下 #4DC1FF → #2FB3FF；橙色从上到下 #FFA048 → #FFD027。
- 雨滴、烟花和笑脸采用本项目自绘单色实形 SVG，使用负形和透明度区分细节；原有无障碍名称与交互保留。右上角三个按钮保持现状。

## 音效编排

| 素材 | 触发与处理 |
| --- | --- |
| shoot（1.800 s） | 每次升空，取中段上升区并按飞行长度淡出，避免拖到爆炸之后；校准原始低响度。 |
| explode（1.392 s） | 写实、礼物主炸；扁平第二轮花朵展开为主炸。扁平第一轮和写实二次小炸只用较轻、短促且音调略随机的该素材。 |
| fireworks2（0.216 s） | 仅主炸后 55 ms 加一层较轻的短回响，小炸不叠加。 |
| shining（3.336 s） | 主炸后中心细密闪点层，压低音量与音调，写实最长 0.85 s、扁平最长 0.55 s；两次写实铺底至少间隔 2 s；礼物完全不播放。 |
| sparks（4.440 s） | 实际分裂成碎点时轻声播放，单段不超过 0.28 s；一组窗口 0.32 s 后停止，下组至少隔 1.8 s。礼物不播放此素材，不循环铺底。 |

五份文件均来自用户桌面 fireworks 文件夹，原样复制。额外收录一段 BenjaminNelan 的 CC0 Paper Rustle，作为礼物碰人后短彩带的真实纸张声，播放 0.17–0.24 s；详见音效素材来源.md。所有音频本地打包，播放时无第三方请求。系统解码检查已完成，已测量时长、起音静音和峰值并在加载时分别校准。工具无法直接听辨音频，主观听感仍需用户试听。

## 加载与性能

六段共 211,379 B，文件名包含内容哈希。加载阶段最多两个并行任务，Web Audio 解码一次并复用缓冲；所有素材解码后才允许特效启动。中央提示包含音效进度和失败重试。触发阶段没有网络、解码或 JS 计时器；同时最多 24 路，细碎事件合并，切换会取消已排程回响。视觉分裂事件与声音共享时点，粒子轨迹及随机布局不变。

265 项回归通过，覆盖预载、并发上限、主炸/小炸、短回响、消散、彩带碰撞、静音取消、失败重试，以及音效等待状态。单色图标与渐变已通过独立渲染检查；真实浏览器音频听感尚未自动验收。

v68 独立归档保留；本版另存源码 ZIP 和对应部署包。发布记录待补充。

用户试听后的调整：升空音降低约 3.5 dB；shining / sparks 明显减弱并限制时长，取消所有无限循环。礼物只有主炸和接触后的纸张声；扁平每朵花的主炸独立变化音量和音调。
