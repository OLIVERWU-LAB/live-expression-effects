Public 仓库。main 保存源码、测试与复盘，gh-pages 保存可运行的精简静态文件。运行 npm test 检查，npm run build 生成 .pages；无应用依赖安装步骤。当前登录无自定义 workflow 写入权限，使用 Pages 官方分支构建，不增加 OAuth 权限。

性能预算、取舍、实测范围见性能与ROI.md。手机摄像头全链路、温升和低端设备 FPS 未在本轮实机验证，不以资源检查替代真实交互验收。
