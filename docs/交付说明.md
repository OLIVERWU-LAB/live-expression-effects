# 交付说明

1. Live Demo：https://oliverwu-lab.github.io/live-expression-effects/
2. Public Source：https://github.com/OLIVERWU-LAB/live-expression-effects
3. Vibe Coding 复盘：[不超过200字，含核心纠偏Prompt](Vibe-Coding复盘.md)

直接打开演示并允许摄像头。微笑下雨，大笑放烟花；三种风格均支持人物轮廓和头部碰撞。锁定播放用于独立检查视觉效果，解除后恢复真实表情控制。未启用摄像头的预览是模拟输入。

运行入口、资源准备进度、失败重试和首个点击提前接入均保留。正式页面移除诊断面板、数字版本标记和历史样式挑选页，URL无需版本参数。历史源码、素材及测试实验另存独立备份，不以当前源码目录继续承载。

当前保留65个实际运行文件；构建另外加入GitHub Pages的.nojekyll标记。图片、音频及模型已压缩；模型解压字节、识别逻辑、烟花参数、雨滴、声音与之前确认的效果保持。具体资源字节与检验范围见[架构与性能](架构与性能.md)。

运行：`npm start`。检查：`npm test`、`npm run verify:assets`。构建：`npm run build`，输出`.pages/`。
