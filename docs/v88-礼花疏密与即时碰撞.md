# 礼花疏密与即时碰撞试作

礼物主粒子取消原来的 0.65 秒碰撞等待，并允许上斜与侧向运动在接触轮廓时立即散成短彩带。彩带保持一次性碰撞，不递归分裂。雨滴、音效、识别模型与表情阈值不变。

扁平的五个载星在分散阶段横向展开更宽，纵向适度拉开。每朵花仍从真实载星位置生成，保持向四周的放射、原来的组件与错峰节奏。桌面避让额外预留花冠空间，窄屏保留最小可播放布局，不移除任何一朵花。

答卷预览的人物下移 32/576 画幅像素；扁平预览使用体验里的发射规划与避让算法。预览保持用户 SVG、纯灰填色、纯黑背景。

验证包括立即侧向碰撞、五朵花的真实出生点间距、手机与桌面完整花型、低粒子预算、自然径向分布、拖尾与识别回归。五组固定随机种子下最近花心距离比上一版增加约 30% 至 52%，没有增加粒子数或新增模型、音频和图集。

实际绘制器通过原生 CPU Canvas 检查；未声称已在用户手机上重新运行摄像头或测量 GPU 帧率。
