# v70 · 移动端资源、完整花型与识别恢复

用户反馈：手机加载慢、雨滴切烟花等待数秒、扁平花型缺失。本轮尝试更小的识别方案后，用户实测表情抖动、张口大笑无法正确触发、头发／身体／手部识别丢失、受光粗糙。因此撤回轻量识别实验，未将该实验发布到线上。它的自动化推理通过不能代表用户的真实识别体验。

## 最终保留的识别能力

恢复 v69 的 MediaPipe 人脸模型、478 点轮廓、左右 mouthSmile blendshape 均值及 ExpressionController 原阈值／滤波。恢复 480px 人脸输入、320px 人物与手部输入、全身分割置信度遮罩和独立手部模型。core.mjs、vision.worker.js、vision-session.mjs、camera-frame.mjs 与改动前文件逐字节相同。没有用张口幅度代替笑容，也没有假装轮廓只需覆盖额头。

人物光照遮罩恢复原来的 512px 宽处理，不降低遮罩质量。写实保留原受光强度；礼物和扁平只保留碰撞，关闭反光，并直接将透明特效叠加在原生摄像头视频上，免去这两种风格的三张纹理上传与逐帧复制摄像头。头部、身体及手部碰撞仍独立计算；手部在下雨和烟花状态都采样。

中央加载提示包含人物轮廓和手部准备阶段，避免只有人脸已就绪就让用户误以为所有识别资产已完成。欢迎页空闲时准备原来的识别引擎和音效，不获取摄像头、不生成表情信号。单在途帧、异常恢复、原生计时器接收者修复均保留。

## 减重与卡顿修复

- 资源大头是学习得到的识别权重和运行库，不是烟花面数。最终保留原识别能力，只发布无损压缩的模型／运行库，不再同时携带原始大文件副本。支持 SIMD 与不支持 SIMD 的运行库二选一下载；现代浏览器使用 DecompressionStream 解压，校验长度与 SHA256。缺少该 API 的旧浏览器明确提示更新。历史原始资源仍保留于完整源码与独立归档。
- 礼物沿用原来的形状、配色、材质烘焙和散射布局，离线选取最多 8 个完整姿态、80px 图块，合并为两张 WebP。每次只绘制一个姿态，禁止叠加旋转帧导致重影。不新增实时三维面片或播放阶段素材解码。两套图共 419,360 B，RGBA 按尺寸合计 13,516,800 B，浏览器/GPU 副本另计。
- 手机原先要求顶点不得高于 104px，且避开头部至少 84px。正常近景人脸经常没有合法发射点，程序反复等待；这不是素材下载。竖屏改用 28px 顶部边界及按头部尺寸调整的安全间隔，发射／爆炸前仍检查人物位置，天空完全占据时取消。
- 扁平降级按每朵花、每个径向层分别均匀采样，保留发射器，先减少碎点和伴星。竖屏载星以真实速度形成适合画幅的五朵小花；保留错落时间、重力和实时爆炸位置。正常串行播放无排队补生的组件；极端人工重叠时，发射器可以等旧细节淡出，已显示组件不会突然裁掉。
- 手机／低核心桌面从第一场限制像素及粒子预算；保留同样拖尾时间长度，采样从 16ms 改为 32ms，圆环用 40 点绘制。桌面常规画布恢复原最高 160 万像素／1.35 DPR，不牺牲人物光照遮罩。

## 雨滴与积水

- 写实、扁平竖屏雨量增加，进入下雨时先铺入 24 颗在途雨滴，其后从上方／来向持续生成，不等第一颗从屏幕顶端落下。粒子总预算继续生效。
- 扁平恢复早期蓝色 #439DCA / #58AED6 / #378BB9，补两种邻近蓝；保留大小、透明度、实心／空心差异与小渐变、高光。
- 删除写实／扁平积水里的七条短装饰波纹、白色水面描边与摄像头水下扭曲。水面改为平滑曲线填色，碰撞高度采用同样的平滑采样。
- 扁平原先到水面只会消失，现在溅起几颗变形圆水珠。水面碰撞碎滴总量限制约 16 颗，短时上抛、下坠并渐隐，不重复分裂，不积成底部颗粒带；人物接触水珠保持原先短暂逻辑。

## 资源口径与验证

正式部署约 16.2 MB，v69 为 53,746,792 B，减少约 70%。完整资源包括 SIMD／非 SIMD 两种后备引擎，不会同时下载两份。真实人脸首次启动仍需 6,320,668 B 压缩资源，额外身体分割 211,275 B、手部 5,813,795 B；后续复用本机缓存。为了恢复识别准确度，不能再宣称首次识别只有 0.8 MB。六段音效共 211,379 B，沿用前轮试听后的编排。准确字节见 v70-resource-budget.json。部署文件大小、实际下载量和解码内存分别统计。

276 项自动化检查通过。覆盖原识别流程／阈值、双 Worker、身体和手部模型保留、全部压缩资源与原件逐字节一致、实际 WASM 编译、加载提示等待辅助识别与音效、320/390/430px 画幅、150/300/420 粒子档位四种扁平花型完整五朵、径向覆盖与清除、雨量和水面碎滴上限。原生 Canvas 输出竖屏雨、水面及花型分帧图。

用户已指出轻量实验不合格；恢复版当时等待本地真人与手机复核，因此没有单独发布。用户随后确认表情和轮廓正常；v71 在此基础上继续调整图标、水面与声音。自动化测试与本机绘制基准不等于手机整链路 FPS、温升或识别准确率验收。旧版独立归档保留，最终版另存源码与部署包。
