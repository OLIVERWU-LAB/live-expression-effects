# v81 · 扁平样式预览

新增独立页面 `flat-preview.html`，列出当前实际播放的四种扁平烟花：01花瓣涟漪、02同心礼花、03星冠绽放、04锦簇花火。编号根据ACTIVE_FLAT_PATTERNS生成，不包含已经退出正式随机播放的历史样式。

预览直接调用现有StickerWorld、drawFlatLaunch和drawFlatFireworks，不重新仿制形状。固定随机种子用于重播与来回拖动的稳定对比，空舞台不加入人物碰撞。每轮完整展示一次升空、第一次炸开、五朵子花与消散；主体验的声音、颜色、动效和识别保持v80。

提供同步播放／暂停、重播、拖动时间进度、单卡放大、保留／不要标记与复制选择。选择仅保存在浏览器本地，不自动删除主体验中的样式。页面不调用摄像头、不播放音效、不加载人脸模型。离屏卡片停止绘制，绘制上限30FPS，页面隐藏后暂停推进；复用现有矢量绘制，没有增加图片、视频或声音资产。

324项自动化检查通过，包括四种样式与正式列表一致、重播及倒退结果一致、五朵子花全部出现、700粒子预算内完整播放并归零、部署包包含独立预览依赖。原生CPU Canvas输出4种样式的多个阶段供视觉核验；没有进行真实浏览器交互或手机实机测试。
