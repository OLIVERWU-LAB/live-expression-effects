# v75 · 节奏、拖尾与轻声音效

## 扁平烟花

- 主要花形比 v74 多保留约 15%–23%：花瓣主体从 1.24 提至 1.50 个模拟秒，径向主体从 1.32 提至 1.62，同心长尾从 1.78 提至 2.05；随机寿命差仍保留。首炸花瓣仍为 0.8 秒，五个散射点的绽放时点不变。
- 下一枚不再等到几乎看不见的细闪、圆环也全部清空。主体进入最后约 0.58 个模拟秒时可以先升空，保留上一组自然收尾；新一组的大炸还需经过完整飞行。发射最低间隔 1.15 秒，仍受现存主体／载星／火箭门控，并维持原粒子预算。
- 竖屏整组统一倍率适度增加约 9%，仍只调整整组炸点与倍率，不将五个散射点重新拉向固定位置。此前已调整好的雨滴尺寸与数量保持不变。
- 长拖尾遇到非有限坐标、时间倒序、异常位置跳跃或急折回时停止连接，限制尾迹长度。长尾网格使用彩色渐变，白色保留在独立的小圆头与细碎闪点，避免整条奶白色尾迹在末段变成亮条。没有删除烟花碰撞，也没有在快结束时直接清空组件。

## 声音

- 三种风格升空改用程序生成的一次性气流燃烧噪声，不使用振荡器滑音或卡通哨声，跟随真实飞行时长渐弱。
- 礼物碰撞的纸屑声改为程序生成的柔软、成簇轻响；撤下偏硬的原纸张录音。主炸、小炸、细闪仍保留用户录音的音色。
- 连续雨声两层增益从 0.46 / 0.16 降至 0.15 / 0.035；人物碰撞改为短促水珠声，并优先于底部水面碰撞，避免较大的池水碎滴抢走头部音效。人物／水面分别限频，最多六路雨声音源。
- Sparks / Shining 从 0.12 / 0.14 降至 0.045 / 0.060；大炸回声从主声的 28% 降至 12%，主炸响度保持原样。停止、切换、静音继续使用渐弱。
- 升空与纸屑 PCM 在音效准备阶段生成并缓存，播放时复用。水滴短声按需生成一次；包括雨声底层在内，四个程序缓冲在 48kHz 下最多 602,880 B。无播放定时器、音频回调或逐粒子音源。
- 正式包不再下载／解码 shoot 和 paper 两段旧切片，保留原文件在源码归档。运行仅下载 explode、fireworks2、shining、sparks 四段录音；没有新增音频下载。

## 验证与限制

308 项自动化检查通过，覆盖连续发射的收尾衔接、既有粒子预算、延长主体而不延迟首炸、断裂尾迹／异常坐标、彩尾和独立白点、程序音色缓存、四段资产准备、人物碰撞优先、混音强弱及节点释放。

用原生 CPU Canvas 对照 v74 逐帧分析同心礼花末段：同一探测规则下，白色长条候选由 7 个降为 0 个，最大白色连通区域跨度由 61 降至 12 CSS 像素。该规则是绘制诊断，不宣称已在真实 iOS WebKit GPU 上复现和测量。

用实际音效类、原录音与真实雨滴／烟花模拟离线渲染，三种雨声平均强度约为 v74 的 36%–39%，能记录到人物碰撞水声，结束后归零并释放音源，无削波。离线工具不能直接听辨主观混音，也未测量手机硬件延迟；最终听感和手机频闪仍需用户实机复看。

原表情模型、判定、人物／手部识别、碰撞几何保持不变。v74 独立归档保留，v75 另存源码与部署包。
