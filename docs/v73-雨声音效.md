# v73 · 补齐三种风格的雨声

v72 漏接雨声音源，雨滴仅有画面。本轮为写实、礼物、扁平接入雨声，未改识别、判定、粒子和碰撞效果。

- 烟花仍使用用户提供的 shoot / explode / fireworks2 / shining / sparks 五段录音；礼物彩带使用已有 CC0 纸张录音。程序只编排触发、响度、声调和自然包络。这些不是纯合成音色。
- 雨声独立用 Web Audio 程序生成：一个 1.6 秒单声道噪声缓冲，经两个滤波层产生连续的轻雨与细雨颗粒；随屏幕内实际雨滴数量调整响度。
- 可见碰撞水花聚合为轻短水声，每秒最多约 8 次，最多 4 路短声，不逐粒子创建声音。三种风格使用同一自然雨声，不添加卡通滑音。
- 无可见雨滴、停雨、风格切换或静音时渐弱并释放。与现有声音共用静音、音频解锁、暂停恢复和主混音器；没有额外音频下载，没有播放定时器或主线程音频回调。
- 新增 PCM 缓冲最多 307,200 B，首次有雨时生成并复用；音频计算交给浏览器音频线程。已确认正常的表情识别、人物轮廓和视觉文件保持不变。

本轮以自动化检查及离线实际粒子／音频渲染检查发声、随雨量变化、静音／切换和节点释放；最终主观听感仍需真实设备试听，未声称测量手机硬件音频延迟。

296 项自动化检查通过。用真实雨滴模拟与当前音效类离线渲染三种风格，峰值约 0.169 / 0.141 / 0.169，无削波；停雨后最后半秒静音，声源全部释放。原录音、识别、判定、粒子和视觉文件与 v72 逐字节一致。
