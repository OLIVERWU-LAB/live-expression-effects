# 对称放射与斜落雨滴

扁平烟花原先在出生时即叠加角度噪声、射线长短变化、统一向上偏移，以及载体剩余速度，造成起爆就偏向一侧。三种现用形式现在按各层固定等角步长发射，相对圆心的对向粒子速度等大反向，不继承载体横向速度。后续仍由重力、阻力、碰撞和原有错落寿命形成弯曲与消散。花朵位置、大小、五朵花的发射编排和间隔保留。

粒子精简同时保留对向粒子，按每朵花与每个层级独立采样；出生预算显式覆盖成对射线、圆环、细闪及同帧附带的尾部闪点，避免精简后又失去对称。未提高设备粒子上限。

礼物雨滴与扁平雨滴同向倾斜落下，保持原有手机尺寸与密度，从顶部及上游侧边补入，避免斜落后左下方缺雨。碰撞后仍为圆形小水滴。

核验：303项自动检查通过，包含三种花型在低密度及15粒子出生配额下的对向匹配。72组连续场景、3240朵花的圆环、必需射线层及细闪无遗漏，队列无积压。答卷预览复用相同代码，封面年份改为ByteDance。
