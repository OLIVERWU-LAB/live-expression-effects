# 四朵错落组合

三种扁平烟花现在每次固定展开四朵。四个花心围绕主爆点向四个方向移动，整组方向随机旋转，每条分支还有小幅角度和距离变化，保留错落的上下关系，取消上一版的水平浅弧排列。四朵按原有节奏依次起爆。

已接受的单朵工厂保持：各层射线的均匀夹角、初始速度、星冠、尺寸、配色与白色细闪寿命均未修改。用相同输入逐项序列化核对三种工厂，结果与上一版一致。花心布局在规划阶段避让头部；空间紧张时适度压缩花心范围，单朵尺寸仍只由视口决定。

固定四朵后，极低粒子预算更容易与上一轮收尾重叠；该档位优先精简新生装饰点与射线数量，仍按完整等角子集保留圆环、射线层和白闪。常规预算的策略保持，没有提高设备上限。

308项检查通过，包含100组随机布局的四向覆盖、非水平排列及单朵工厂一致性。72组连续场景、2592朵花的必需层与白闪无缺失，队列无积压。体验页与答卷预览共用相同布局和绘制代码。

已核对原生Canvas输出；Work设置仍关闭浏览器操作，本轮未进行手机实机或摄像头复测。
