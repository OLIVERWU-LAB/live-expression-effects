# v65 · 移动端体验修复

1. 三种风格增加竖屏雨量下限，写实雨线进一步加粗。固定种子、390×844、运行 3 秒的同一时点，可见主雨滴从写实 10、礼物 24、扁平 11，变为 41、52、50；此为模拟快照，不是设备 FPS。
2. 礼物素材加载、首次识别准备和识别重建均在中央提示。素材失败提供重新加载入口，避免空白等待；手机解码图块缩至 96 像素，每套最多 4 个并发任务。
3. 取消一次错误就永久停在“重试识别”的行为。单帧异常丢弃，连续失败或超时自动重建，前台持续重试。后台暂停、返回后继续。Worker 身份和帧号隔离迟到结果，防止旧回调清除新任务。真实无人脸仍恢复待机。
4. 扁平低预算不再抽掉负责后续绽放的载星和花心；不提前回收正在显示的主体。不因横向越界直接删除活组件，新场不挤掉旧场；竖屏整组花型适配可见画幅。桌面尺寸与既定形态、时序保持。
5. 扁平人物受光关闭，写实受光增益提高至 1.6，礼物维持 1.7。
6. 发布模块与 Worker 使用统一内容版本，避免手机缓存混用不同版本。

246 项自动化测试通过。补充了真实 app 在模拟浏览器环境中的启动、礼物加载提示、风格切换、相机初始化和停止检查，以及原生 Canvas 竖屏画面对照。未在手机真机上执行摄像头连续运行、温升与全链路帧率验收，不承诺所有浏览器均无问题。
