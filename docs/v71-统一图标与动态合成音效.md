## 控件与水面

雨滴、烟花、笑脸使用同一 24px 网格、1.7px 圆角笔画与少量实形细节，统一单色和视觉重量；不添加图标字体或运行库。网页中的路径与图标源定义逐项一致。

三种风格共用平滑水面和一条细高光：写实 1.15px，礼物／扁平 1.3px。保留 v70 平滑曲线，不恢复七条内部短波纹或粗白描边。写实在现有合成里使用连续、低幅度的水下折射；礼物／扁平对水面以下区域直接采样原生视频，最多 24 条窄带，不上传整屏到新增 WebGL 通道，不每帧创建画布或抓取像素。受光规则保持：写实反光，礼物／扁平仅碰撞。

## 声音行为

用代码生成气流、爆炸、亮点和纸片四种基础声音纹理，替换正式体验中的 MP3 播放。保留用户 MP3 和原采样实现仅供源码追溯，不再进入正式部署依赖；用户桌面原文件未改动。

- 升空：气流、轻微哨声与滤波扫频，时长随该枚烟花的升空时长调整，保持较轻音量。
- 大炸：低频冲击加逐渐衰减的噪声燃烧质感，按大小调整力度，音调和音量有有限随机变化；约 75–100ms 后有较轻、偏低频的余响。
- 小炸：更短、更轻、音调稍高，无独立余响。扁平首爆为小炸，后续几朵花各有不同的音量、音调和声像；写实主炸较强、复绽较轻；礼物只有一次主炸。
- 细闪：每 50ms 聚合检查屏幕内仍在发亮的粒子、生命期及淡出程度，密度、力度和声像据此变化；没有可见亮点时不生成新声音。每个窗口最多五颗轻微颗粒声，有明确静音间隔，已有颗粒使用自身完整衰减收尾，不截取长音效的中段。
- 礼物碰撞：只在视觉彩纸碰撞事件时触发一小段程序噪声纸张摩擦，不生成闪光铺底。
- 切换／静音以短包络淡出，取消未来的余响；暂停复用既有生命周期。音源结束后释放，另有基于音频时钟的有界回收，防止浏览器漏发 ended 时积累。

## 性能与验证

四种纹理只在准备阶段生成一次，共 355,452 B 单声道 PCM，播放时复用；不下载音频、不解码 MP3、不创建卷积混响、不逐粒子创建声源、不用 JS 定时器派发声音。最多 18 路活动声源，并为升空和主炸预留六路；声源时间和包络交由 AudioContext 时钟。正式依赖约 16.0 MB，识别资源与 v70 相同。

286 项自动化检查通过，新增包括：波形有界且首尾为零、重复准备不重新生成、阶段映射、音量音调变化、没有可见粒子时静音、礼物无细闪铺底、密集事件声源上限及释放、切换取消余响与渐弱收尾、图标路径统一、水面单一高光及局部折射范围。历史采样版测试改为验证归档实现，不用于冒充程序音效验收。

另使用临时安装的 Node Web Audio 实现，运行实际 SoundDesigner 和粒子事件并导出三种风格七秒 WAV。三段最大绝对样本约 0.149 / 0.098 / 0.149，无削波；最后半秒静音，结束后声源均释放；峰值活动音源 8 / 12 / 3。导出仅用于 QA，不进入网页。此检查不等于主观听感、真实浏览器音频硬件延迟或手机 FPS 验收；当前工具不能直接听辨混音，已邀请用户试听本地版本。
