# v83 · 整组烟花避让

## 改动

- 从正式扁平随机播放和独立样式预览移除「花瓣涟漪」。其余编号保持02同心礼花、03星冠绽放、04锦簇花火，避免上一轮选择对应关系变化。历史备份及内部回归用的旧形态保留；第一次爆炸的装饰花瓣继续保留。
- 原布局只检查初次爆点，竖屏进行整组缩放，电脑端基本沿用初次爆点；五个继续散开的载星会在靠近头部的位置二次绽放，甚至中心落入头部。新增flat-placement模块，在每次发射前以实际载星运动预测五个展开中心，并保留展开后的轨迹余量。
- 电脑横屏优先利用头部两侧和上方，手机竖屏优先利用头顶和上侧空位。布局根据实际头部边界和屏幕空间选整组位置、尺度及一套自然随机方向。五个载星保持原来的角度分布、速度关系、减速和错开时间；后续射线仍向四周自然展开，不单独把某朵花推到另一侧。
- 用同一随机种子连接布局预测与真实升空后的生成，确保预测的五朵就是实际五朵。选位只在每次发射时运行一次，最多16档尺度、8套随机布局和固定大小位置网格；没有每帧试跑整套世界或额外模型推理。
- 手机展开中心保留34–52px基础头部距离，电脑52–84px；另按花的尺度加入展开余量。屏幕边缘同时计入载星残余速度，避免只让中心可见、射线却被裁掉。空间不足时整体适配，不保持一个已被头部占据的大烟花尺寸。
- 发射前保存五个预测点。到顶点时如头部已显著移入预留区域，整发取消并沿用现有100ms内重新选位机制，避免先炸一半再挪动或漏掉部分子花；正常小幅头动由预留余量吸收。若人像占满可用天空、没有安全展开空间，返回无布局，不强行在头部炸开。

雨滴、声音、表情及轮廓模型、同心礼花弧线和星冠加长拖尾保持v82，发射间隔不变。新增约4KB程序代码，没有新增媒体资产。

## 验证

328项自动化检查通过。新增检查覆盖：花瓣从正式列表移除且剩余编号稳定；320/390/430手机竖屏、1280/1440电脑横屏、三种样式及15/60FPS时序下，五个实际展开点全部出现并与头部保持距离；不改变整组原始径向方向和错开时间；人物大幅移入预留位置时整发取消，无半朵残留。

既有低预算检查继续覆盖150/300/420粒子、全部五个子花、内层细闪、最终消散、无排队出生残留。对应直接爆点测试改为传入同一选位种子，和真实升空流程一致。旧「电脑完全不调整／极近竖屏始终保持大尺寸」断言随本轮需求调整；屏幕无头部时仍保持原有电脑布局。

实际Renderer与世界的移动头部／遮挡对照样本中：390×844手机最小展开中心距头部由约11px增至79px，1280×800电脑由0增至137px；六组样本在子花出现前0.5秒内的碰撞数从613降至3。该数字是固定录制输入的对比，不代表真实设备统一提升比例。

390×690手机画幅、15/24FPS、连续发射、移动轮廓遮挡的完整绘制中，三种样式均未超过420粒子，长白条候选为0。使用原生CPU Canvas，未实际调用摄像头或实机验证iOS GPU。
