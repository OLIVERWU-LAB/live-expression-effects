# v85 · 自然疏密

在v84向四周展开的结构上，为正式扁平的三种花增加小幅稳定变化：各层射线的角间距按花本身的种子轻微错开，偏移不超过一个标准间距的14.5%；径向初速轻微变化，最大约±10%，让射线长短不再完全齐整。

变化由原有粒子种子和层号计算，整段轨迹不会每帧抖动，不新增随机数调用，也不新增粒子或额外绘制。仍然完整覆盖四周，不增加共同朝某一侧的速度，不恢复上轮的单边偏向。

整组选位与头部避让、五个载星的轨迹和出生时间、粒子数量与生命周期、颜色、拖尾长度和发射间隔保持v84。声音、雨滴、人物和表情识别不变。新增416字节代码，没有增加媒体资产。

## 验证

330项自动化检查通过。既有径向检查覆盖三种样式、三档尺度、15套随机种子和五个子花，仍覆盖四个方向，载星共同漂移保持限额。预算、五朵花完整出现、自然消散、手机低帧率、识别与音频检查继续通过。

与v84逐字段比较，144组电脑／手机布局完全一致。每种样式360朵展开样本的主射线均覆盖四个象限，没有恢复单边扫出的情况，方向偏置保持与v84相近。实际Renderer移动头部及遮挡对照、手机画幅15/24FPS连续发射检查中，没有长白条候选，粒子不超过420。这些为原生CPU Canvas与模拟验证，未进行真实摄像头／手机GPU测试。
