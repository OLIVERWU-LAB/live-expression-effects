# v82 · 弧线与星冠拖尾

按预览编号调整两种扁平烟花，主体验与独立样式预览共用同一份代码：

- 02同心礼花：仅彩色彗星射线的径向初速降低8%，重力从115√scale改为145√scale，让放射稍慢、自然下垂弧度更明显。升空、五个子花的位置与触发时间、拖尾采样和末段淡出保持不变。
- 03星冠绽放：主星尾迹与彩色彗星射线的可见历史由0.27–0.28秒增至0.56秒，最多40个历史点，空间长度上限由100scale增至170scale。保留真实运动轨迹，不绘制独立刚性长条。粒子生命、发射速度、星星大小与颜色不变；增加的是可见拖尾长度，不是动画持续时间。

01花瓣涟漪和04锦簇花火的运动未改动；声音、雨滴、识别、发射间隔不变。本轮没有增加媒体资源，部署内容仅增加232字节。

## 核验

324项检查通过。实际v81／v82世界逐帧对照覆盖4种样式及桌面16ms、手机32ms轨迹采样：逐粒子的数量、寿命、大小、随机种子、颜色及子花编号完全一致；01和04的位置也完全一致，全部在4.8秒预览循环前归零。1.8秒样本中星冠彩色射线的平均可见轨迹从约17–18舞台像素增至39–40，约2.2倍；手机采样最多18个历史点，桌面最多36个，低于40点上限。

实际Renderer在390×690画幅、15／24FPS、移动人物遮挡与碰撞、连续发射情形下检查02和03：粒子不超过420，最终长白条候选为0。保留已有手机长拖尾防护：同心礼花尾部仍用有界纯色四边形绘制，末段迅速淡出。该检查使用原生CPU Canvas，不能替代真实iOS GPU测试。
