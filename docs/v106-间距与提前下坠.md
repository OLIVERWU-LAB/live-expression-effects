# 扁平烟花：间距与提前下坠

五朵花沿用已确认的组合、随机种子、单朵大小和均匀出射角度。五个花心间距适度增加，最大约12%；头部或画面边缘空间紧时逐级减小增幅，保持原有安全距离，不缩小单朵。

炸开之后的重力提高60%，让向上、向侧面的射线更早转为下坠。初始速度、出射角度、组件数量、大小与生命周期保持不变，升空和第一次0.8秒的开花过渡也保持原样。

增强下坠会增加同一时间到达人像附近的粒子数。粒子池达到80%时，不再新增额外的外围装饰细闪，主花形、环、内外层射线及原有细闪保留；不提高粒子预算，不直接清除仍可见的组件。

验证：312项自动检查通过；72组连续模拟覆盖3240朵花，环及必需主组件无丢失，最大排队数为0。原生Canvas核对桌面和竖屏绘制，答卷预览采用相同代码。模型、音效、贴图未新增或替换。本轮未进行浏览器摄像头或手机实机复测。
